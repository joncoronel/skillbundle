# Security Policy

## Reporting a vulnerability

Please don't open a public issue for security problems.

Email **support@skillbundle.dev** with a description of the issue, the steps to reproduce it, and the impact you think it has. You'll get a reply once I've looked into it, and I'll keep you updated until it's fixed.

## Scope

- The live app at [skillbundle.dev](https://skillbundle.dev)
- The code in this repository

Report issues in the services SkillBundle uses (Clerk, Convex, Polar, Vercel, skills.sh) to those providers directly.
